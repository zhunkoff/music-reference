# music-reference

Справочные таблицы и документы по музыке для обучения, практики и использования
в собственных проектах.

## Материалы

Первый документ — таблица аппликатур аккордов для шестиструнной
гитары в стандартном строе E A D G B E, от шестой струны к первой.

- [PDF на английском](guitar/chords/6-string-standard-tuning.en.pdf), [без номеров пальцев](guitar/chords/6-string-standard-tuning.en-dots.pdf)
- [PDF на русском](guitar/chords/6-string-standard-tuning.ru.pdf), [без номеров пальцев](guitar/chords/6-string-standard-tuning.ru-dots.pdf)
- [Исходник TeX с поддержкой русского и английского](guitar/chords/6-string-standard-tuning.tex)

Материалы сгруппированы по инструментам и темам. PDF и исходник TeX каждого
документа хранятся рядом.

## Сборка таблицы

После установки TeX Live и `just` выполните эту команду из корня репозитория,
чтобы собрать все зарегистрированные документы на английском.

```sh
just build
```

Таблица сохраняется в `guitar/chords/6-string-standard-tuning.en.pdf`.
Для русского используйте `just build ru`, для обоих языков — `just build-all`.
По умолчанию номера пальцев видны. Команда `just build en false` собирает
английскую версию с точками без цифр, `just build-all false` — обе языковые версии.
Установка инструментов для Windows, Linux и macOS и подробные инструкции
описаны в [руководстве по сборке](BUILD.ru.md).
