# Сборка PDF

Руководство описывает сборку документов из исходников TeX в Docker и с помощью
инструментов, установленных в Windows, Linux или macOS. Вернуться к
[обзору проекта](README.ru.md).

## Сборка в Docker

Используйте Docker с Linux-контейнерами. [Dockerfile](Dockerfile) устанавливает
в образ инструменты TeX, шрифты, `just` и YAML::PP. Соберите образ из корня
репозитория и пересобирайте его после изменений Dockerfile.

```sh
docker build -t music-reference-build .
```

В Linux или macOS выполните эти команды из корня репозитория. В Linux с обычным
Docker Engine параметр `--user` задаёт для создаваемых файлов ваши UID и GID.
Если вы используете rootless Docker, опустите `--user`, чтобы Docker сопоставил
пользователя контейнера по умолчанию с вашим пользователем на хосте.
[Сопоставление UID и GID в Docker](https://docs.docker.com/engine/security/rootless/uid-gid-mapping/).

```sh
docker run --rm --user "$(id -u):$(id -g)" --mount "type=bind,source=$PWD,target=/workspace" music-reference-build build-all
docker run --rm --user "$(id -u):$(id -g)" --mount "type=bind,source=$PWD,target=/workspace" music-reference-build build-book en
docker run --rm --user "$(id -u):$(id -g)" --mount "type=bind,source=$PWD,target=/workspace" music-reference-build build-book ru
```

В Windows выполните эти команды из того же каталога в PowerShell.

```powershell
docker run --rm --mount "type=bind,source=$($PWD.Path),target=/workspace" music-reference-build build-all
docker run --rm --mount "type=bind,source=$($PWD.Path),target=/workspace" music-reference-build build-book en
docker run --rm --mount "type=bind,source=$($PWD.Path),target=/workspace" music-reference-build build-book ru
```

Аргументы после имени образа передаются напрямую в `just`. Например,
`build-fretboard en octaves` собирает один вариант карты грифа, а `clean` удаляет
вспомогательные файлы. `build-all` собирает оба языка и оба режима подписей грифа.
Отдельные PDF сохраняются рядом с исходниками TeX, а сборники — в файлы
`build/music-reference.en.pdf` и `build/music-reference.ru.pdf`. Контейнер читает
необязательный `build.yaml` из смонтированного репозитория. Допустимые настройки
и их переопределение аргументами описаны в разделе
[«Конфигурация сборки»](#конфигурация-сборки).

## Необходимые инструменты

Команды проекта описаны в `justfile` и используют `latexmk`, который запускает
LuaLaTeX необходимое число раз. Для таблицы гитарных аккордов используются TikZ,
Babel с данными английского и русского языков и шрифты DejaVu Sans Condensed
обычного и жирного начертаний.
Для обработчика очистки проекта нужен `latexmk` версии 4.84 или новее.
[Документация latexmk](https://www.cantab.net/users/johncollins/latexmk/index.html).

| Компонент | Пакет TeX Live |
| --- | --- |
| Автоматизация сборки | `latexmk` |
| Движок LuaLaTeX и механизм загрузки шрифтов | `luatex`, `luaotfload` |
| Встроенные расчёты Lua в таблице частот нот | `luacode` |
| Схемы TikZ | `pgf` |
| Поддержка языков | `babel`, `babel-english`, `babel-russian` |
| Английские и русские переносы | `hyphen-english`, `hyphen-russian` |
| Выбор шрифтов | `fontspec` |
| Шрифты DejaVu Sans Condensed | `dejavu` |
| Символы нотной записи | `lilyglyphs` |
| Разметка страницы и вспомогательные команды | `geometry`, `etoolbox`, `hyperref` |
| Сборник PDF | `pdfpages`, `newpax`, `bookmark`, `xcolor` |

Полная установка TeX Live включает эти компоненты и их зависимости. Для загрузки
и установки потребуется несколько гигабайт. В инструкции для Gentoo необходимые
коллекции выбираются настройками Portage. Уже установленное окружение можно
проверить командами из раздела [«Проверка установки»](#проверка-установки).

Установите `just` отдельно по инструкции для своей платформы ниже. Для систем
со старыми репозиториями пакетов также доступны официальные бинарные файлы.
[Установка just](https://just.systems/man/en/installation.html).

Для необязательного локального файла `build.yaml` нужен YAML::PP версии 0.027
или новее для того Perl, который запускает latexmk. Стандартная сборка в свежей
копии репозитория и прямая компиляция через LuaLaTeX работают без этого модуля.
[Документация YAML::PP](https://metacpan.org/pod/YAML::PP).

## Установка инструментов

### Windows

1. Скачайте `install-tl-windows.exe` со страницы сетевой установки TeX Live.
2. Запустите установщик и выберите полную схему установки `scheme-full`.
3. Оставьте включённым добавление TeX Live в путь поиска исполняемых файлов
   и завершите установку.
4. Установите `just` из PowerShell с помощью Windows Package Manager.

```powershell
winget install --id Casey.Just --exact
```

После установки откройте новое окно PowerShell и выполните проверки ниже.
В Windows команды проекта выполняются через PowerShell.
[Пакеты just](https://just.systems/man/en/packages.html).

Установщик и инструкции для платформы поддерживает TeX Users Group.
[Сетевой установщик TeX Live](https://tug.org/texlive/acquire-netinstall.html),
[TeX Live для Windows](https://tug.org/texlive/windows.html).

### Linux

Приведённые ниже команды предназначены для Debian/Ubuntu, Fedora, Gentoo
и SUSE/openSUSE. Выполните команды для своего дистрибутива в терминале.

#### Debian 13+ и Ubuntu 24.04+

```sh
sudo apt update
sudo apt install texlive-full just
```

Пакет `texlive-full` устанавливает коллекции TeX Live, доступные в дистрибутиве.
Поставляемый выпуск зависит от версии операционной системы.
[Пакет Debian](https://packages.debian.org/trixie/texlive-full),
[Пакет Ubuntu](https://packages.ubuntu.com/noble/texlive-full).

#### Fedora

```sh
sudo dnf install texlive-scheme-full just
```

Этот пакет устанавливает полную схему TeX Live из Fedora.
[Пакет Fedora](https://packages.fedoraproject.org/pkgs/texlive/texlive-scheme-full/).

В перечисленных выше дистрибутивах пакет `just` доступен через `apt` и `dnf`.
[Пакеты just](https://just.systems/man/en/packages.html).

#### Gentoo

Добавьте следующую запись в конфигурацию `/etc/portage/package.use`. Если этот
путь является каталогом, поместите запись в отдельный файл, например
`/etc/portage/package.use/texlive`.

```text
app-text/texlive extra graphics luatex music l10n_en l10n_ru
```

Эти флаги выбирают дополнительные шрифты и пакеты LaTeX, графические пакеты,
LuaTeX, поддержку нотной записи и коллекции для английского и русского языков.
[Пакет TeX Live в Gentoo](https://packages.gentoo.org/packages/app-text/texlive).

Выполните команду установки от имени root.

```sh
emerge --ask app-text/texlive dev-tex/latexmk dev-build/just
```

Portage установит выбранные коллекции TeX Live и оба инструмента сборки.
[Пакет latexmk в Gentoo](https://packages.gentoo.org/packages/dev-tex/latexmk),
[Пакет just в Gentoo](https://packages.gentoo.org/packages/dev-build/just).

#### SUSE / openSUSE

На SUSE Linux Enterprise подключите расширение Package Hub для зарегистрированного
выпуска системы. Выведите список расширений и выполните показанную команду
активации Package Hub для своего сервис-пака и архитектуры.
[Подключение SUSE Package Hub](https://packagehub.suse.com/how-to-use/).

```sh
sudo SUSEConnect --list-extensions
```

На openSUSE используйте репозитории, настроенные для своего выпуска. На обеих
системах обновите метаданные репозиториев и проверьте доступность нужных пакетов.

```sh
sudo zypper refresh
zypper search -s texlive-scheme-full
zypper search -s texlive-latexmk-bin
zypper search -s just
```

Установите полную схему TeX Live, пакет исполняемого файла `latexmk` и `just`.

```sh
sudo zypper install texlive-scheme-full texlive-latexmk-bin just
```

Доступность пакетов зависит от выпуска и подключённых репозиториев. В каталоге
SUSE перечислены схема TeX Live, пакеты исполняемых файлов и `just`.
[Схемы TeX Live](https://packagehub.suse.com/packages/texlive-filesystem/),
[Исполняемые файлы TeX Live](https://packagehub.suse.com/packages/texlive/),
[Пакет just](https://packagehub.suse.com/packages/just/).

Если пакет отсутствует для вашего выпуска, используйте установщик TeX Live
и официальные бинарные файлы `just` по ссылкам в этом руководстве, затем выполните
приведённые ниже проверки установки.

Для других дистрибутивов Linux или установки актуального выпуска TeX Live напрямую
следуйте руководству установщика TeX Users Group. После установки добавьте
выведенный установщиком каталог исполняемых файлов в `PATH` своей оболочки.
[Руководство по установке TeX Live](https://tug.org/texlive/quickinstall.html).

Если при установке TeX Live напрямую пакет `latexmk` был пропущен, добавьте его
командой `tlmgr install latexmk` с правами, соответствующими этой установке.

### macOS

1. Скачайте `MacTeX.pkg` со страницы загрузки MacTeX.
2. Запустите установщик пакета и включите полный компонент TeX Live.
3. Установите `just` через Homebrew или из официального бинарного файла по ссылке выше.
4. Откройте новое окно Terminal и выполните проверки установки, приведённые ниже.

MacTeX содержит дистрибутив TeX Live и настраивает его инструменты командной строки.
[Загрузка MacTeX](https://tug.org/mactex/mactex-download.html).

Если вы уже используете Homebrew, оба инструмента можно установить следующими
командами. После их завершения откройте новое окно Terminal.
[Пакет MacTeX для Homebrew](https://formulae.brew.sh/cask/mactex),
[Пакеты just](https://just.systems/man/en/packages.html).

```sh
brew install --cask mactex
brew install just
```

### YAML::PP

Выполните эти шаги, если планируете использовать локальный `build.yaml`.

На Linux и macOS установите YAML::PP через менеджер пакетов или выполните
`cpan YAML::PP` с тем Perl, который использует latexmk. Если CPAN предлагает
выбрать каталог установки, выберите `local::lib` для установки в домашний
каталог и примените настройки оболочки, которые выведет CPAN. Например,
если модули установлены в `~/perl5`, добавьте в файл запуска оболочки
следующую строку.

```sh
export PERL5LIB="$HOME/perl5/lib/perl5${PERL5LIB:+:$PERL5LIB}"
```

На Windows установите полноценный дистрибутив Perl, например Strawberry Perl,
добавьте его `perl.exe` в `PATH` и выполните `cpan YAML::PP` в новом окне
PowerShell. Добавьте `TEXLIVE_WINDOWS_TRY_EXTERNAL_PERL = 1` в `texmf.cnf`
в корне установки TeX Live, чтобы программа запуска использовала этот Perl
для latexmk. Проверьте доступность модуля командой из следующего раздела.
Сборка на Windows пока не проверена. [Руководство TeX Live](https://tug.org/texlive/doc/texlive-en/texlive-en.html).

## Проверка установки

В PowerShell на Windows проверьте, какой исполняемый файл будет запущен.

```powershell
Get-Command just
Get-Command latexmk
Get-Command lualatex
```

В Bash или Zsh на Linux/macOS используйте следующую команду.

```sh
command -v just latexmk lualatex
```

Остальные проверки подходят для PowerShell, Bash и Zsh. Каждая команда `kpsewhich`
должна вывести путь к запрошенному файлу.

```sh
just --version
latexmk -v
lualatex --version
kpsewhich fontspec.sty
kpsewhich luacode.sty
kpsewhich babel.sty
kpsewhich babel-english.tex
kpsewhich babel-russian.tex
kpsewhich tikz.sty
kpsewhich DejaVuSansCondensed.ttf
kpsewhich DejaVuSansCondensed-Bold.ttf
kpsewhich lilyglyphs.sty
kpsewhich emmentaler-16.otf
kpsewhich geometry.sty
kpsewhich etoolbox.sty
kpsewhich hyperref.sty
kpsewhich pdfpages.sty
kpsewhich newpax.sty
kpsewhich bookmark.sty
kpsewhich xcolor.sty
```

Если вы используете локальный `build.yaml`, проверьте, что latexmk видит YAML::PP.

```sh
latexmk -e 'require YAML::PP; YAML::PP->VERSION(0.027);' -v
```

## Сборка документов

Скачайте или клонируйте репозиторий и откройте PowerShell на Windows либо терминал
с Bash/Zsh на Linux/macOS в корневом каталоге репозитория. На каждой платформе
используются одинаковые команды `just`.

```sh
just build
just build ru
just build-all
```

| Команда | Действие |
| --- | --- |
| `just build` | Собрать все зарегистрированные документы с настройками из конфигурации |
| `just build en` | Собрать все зарегистрированные документы на английском |
| `just build ru` | Собрать все зарегистрированные документы на русском |
| `just build-book` | Собрать сборник PDF на языке по умолчанию из конфигурации |
| `just build-book en` | Собрать сборник PDF на английском |
| `just build-book ru` | Собрать сборник PDF на русском |
| `just build-all` | Собрать все зарегистрированные документы на обоих языках, включая четыре PDF карты грифа |
| `just build en false` | Собрать документы на английском без номеров пальцев |
| `just build ru false` | Собрать документы на русском без номеров пальцев |
| `just build-all false` | Собрать оба языка без номеров пальцев, включая четыре PDF карты грифа |
| `just build-fretboard en octaves` | Собрать только английскую карту грифа с номерами октав |
| `just build-intervals en` | Собрать только справочник по интервалам на английском |
| `just build-chord-construction en` | Собрать только справочник по построению аккордов на английском |
| `just build-circle-of-fifths en` | Собрать только справочник по квинтовому кругу на английском |
| `just build-chords-in-keys en` | Собрать только справочник по аккордам в мажоре и миноре на английском |
| `just build-scale-construction en` | Собрать только справочник по построению гамм и пентатоник на английском |
| `just build-guitar-scales en` | Собрать только карты гамм на грифе гитары на английском |
| `just build-guitar-pentatonics en` | Собрать только карты пентатоник на грифе гитары на английском |
| `just build-guitar-improvisation en` | Собрать только пособие по гитарной импровизации на английском |
| `just build-triads en` | Собрать только схемы обращений трезвучий на английском |
| `just clean` | Удалить вспомогательные файлы зарегистрированных документов |
| `just --list` | Показать доступные команды |

### Конфигурация сборки

Чтобы настроить сборку, скопируйте [build.example.yaml](build.example.yaml)
в `build.yaml` в корне репозитория и отредактируйте копию. Git игнорирует
локальный файл. В примере перечислены все зарегистрированные исходники
и поддерживаемые ими опции. Разделы `defaults`, `documents` и `book` необязательны.
В `documents` используйте точные пути из реестра в [latexmkrc](latexmkrc),
относительно корня репозитория и с прямыми косыми чертами. Настройка `book`
описана в разделе [«Сборник PDF»](#сборник-pdf).

| Ключ | Значения | Исходники |
| --- | --- | --- |
| `language` | `en` или `ru` | Все зарегистрированные документы |
| `accent_color` | `"#RRGGBB"` в кавычках, с шестью шестнадцатеричными цифрами | Все зарегистрированные документы, только в `defaults` |
| `show_finger_numbers` | Логическое значение YAML `true` или `false` | Таблица гитарных аккордов |
| `fretboard_labels` | `notes` или `octaves` | Карта нот на грифе гитары |

Встроенные значения совпадают со значениями в исходниках TeX
(`en`, `"#195755"`, `true` и `notes`). Значения в `defaults` переопределяют
их для исходников, которые поддерживают эти настройки. Запись в `documents`
имеет приоритет для своего исходника. Явные позиционные аргументы имеют
приоритет при текущем запуске.
Если аргумент пропущен, действует значение из конфигурации. При отсутствии
файла конфигурации действуют встроенные значения. До запуска LaTeX проверяется
весь файл. Сборка сообщает об ошибках синтаксиса, повторяющихся или неизвестных
ключах, неизвестных путях, недопустимых значениях и опциях, которые указанный
исходник не поддерживает.

```yaml
defaults:
  language: en
  accent_color: "#195755"
  show_finger_numbers: false
  fretboard_labels: notes
documents:
  guitar/chords/6-string-standard-tuning.tex:
    show_finger_numbers: true
  guitar/fretboard/6-string-fretboard.tex:
    language: ru
    fretboard_labels: octaves
```

С такой конфигурацией `just build` собирает английскую таблицу аккордов
с номерами пальцев и русскую карту грифа с номерами октав. Команда
`just build en false` выбирает английский для всех документов и точки без
цифр для таблицы аккордов. На карте грифа сохраняются номера октав. Команда
`just build-fretboard en notes` явно выбирает английский и названия нот
для карты грифа.

Команда `just build-all` всегда собирает оба языка и оба режима подписей
грифа. Она использует настройку номеров пальцев из конфигурации, если
аргумент её не переопределяет.

`defaults.accent_color` задаёт акцентный цвет для отдельных PDF, оглавления
и разделов сборника на обоих языках и во всех вариантах схем. Кавычки
нужны, чтобы YAML прочитал начальный `#` как часть строки. После смены
цвета запустите сборку снова, чтобы обновить PDF по тем же путям.
При прямой сборке через LuaLaTeX используется значение TeX по умолчанию
`#195755`.

### Сборник PDF

```sh
just build-book
just build-book en
just build-book ru
```

Язык сборника берётся из явного аргумента, затем из `defaults.language`.
Если оба значения пропущены, используется `en`. Этот язык применяется
ко всем разделам, закладкам и метаданным. Настройки языка отдельных
исходников действуют при сборке отдельных PDF. Для разделов сборника
применяются выбранные настройки номеров пальцев и подписей грифа.
Результат сохраняется в `build/music-reference.en.pdf` или
`build/music-reference.ru.pdf`. При смене варианта раздела, акцентного цвета
или настройки оглавления сборник пересобирается по тому же пути без очистки.

По умолчанию сборники на обоих языках начинаются с оглавления на альбомном
листе A4. Каждая строка показывает номер первой страницы раздела в сборнике
и служит ссылкой на эту страницу. Настройка `book.table_of_contents` принимает
логические значения YAML `true` и `false`. Если ключа или файла `build.yaml`
нет, используется `true`. Чтобы убрать оглавление, добавьте в `build.yaml`
следующую настройку.

```yaml
book:
  table_of_contents: false
```

При `false` первый раздел начинается на странице 1. Настройка действует
для `just build-book` на обоих языках. Для проверки печати выберите альбомный A4
и масштаб 100% / фактический размер.

Сборка компилирует выбранные варианты и включает каждый документ один раз
в порядке из [latexmkrc](latexmkrc). Из этого реестра берутся названия и порядок
разделов в оглавлении и закладках. LuaLaTeX компилирует
[обёртку сборника](book/music-reference.tex). Пакет `pdfpages` вставляет страницы
в исходных размерах, а `newpax` восстанавливает кликабельные ссылки. Ссылки между
разделами сборника открывают соответствующие страницы. Из отдельных PDF ссылки
ведут в нужные разделы README на выбранном языке. Сборники и промежуточные
файлы хранятся в `build/`.

При подготовке выпуска укажите его тег в ссылках для скачивания в обоих README.
Соберите обе языковые версии в свежей копии репозитория на коммите выпуска.
Проверьте закладки и ссылки, затем вручную прикрепите оба PDF к GitHub Release
для этого тега. Генерируемые PDF храните вне Git.

### Отдельные PDF

По умолчанию выбран английский язык. `latexmk` автоматически выполняет повторные
проходы и проверяет необходимость пересборки. Повторный `just build` после успешной
сборки использует актуальные результаты.

Готовые PDF записываются рядом с исходником TeX каждого документа. Для таблицы
гитарных аккордов файлы появятся в `guitar/chords`.

| Файл | Содержимое |
| --- | --- |
| `6-string-standard-tuning.en.pdf` | Таблица на английском |
| `6-string-standard-tuning.ru.pdf` | Таблица на русском |
| `6-string-standard-tuning.en-dots.pdf` | Таблица на английском без номеров пальцев |
| `6-string-standard-tuning.ru-dots.pdf` | Таблица на русском без номеров пальцев |

Таблица частот нот сохраняется в `theory/pitch`.

| Файл | Содержимое |
| --- | --- |
| `note-frequencies.en.pdf` | Таблица частот нот на английском |
| `note-frequencies.ru.pdf` | Таблица частот нот на русском |

Каждая языковая версия занимает одну страницу A4 в альбомной ориентации,
охватывает C0-B10 и выделяет условный диапазон слуха 20 Гц-20 кГц. Для проверки
читаемости и обозначений при чёрно-белой печати выберите A4, альбомную ориентацию
и масштаб 100% / фактический размер.
Также проверьте совмещённые метки границ и указанные в легенде конфигурации
инструментов, строи и условную верхнюю границу контрабаса.

По умолчанию номера пальцев видны. Необязательный второй аргумент `just build`
принимает `true` или `false`; `just build-all` принимает тот же аргумент после
имени команды. Например:

```sh
just build ru false
just build-all false
```

Варианты `false` получают суффикс `-dots` и сохраняются отдельно от PDF с номерами.
Скрываются только цифры пальцев внутри точек, включая точки на баррэ. Точки,
баррэ, номера ладов и обозначения открытых и заглушённых струн сохраняют положение.
В пояснении описываются точки без цифр вместо номеров пальцев.

Таблица частот нот всегда сохраняется под стандартным именем для своего языка.

При прямой сборке гитарной таблицы через LuaLaTeX определите `\ShowFingerNumbers`
как `false` до загрузки исходника. Значение по умолчанию — `true`. Недопустимые
значения языка или показа номеров пальцев прерывают сборку с ошибкой.

Каждый PDF с гитарными аккордами содержит две страницы A4 в альбомной ориентации и
всего 96 схем. Откройте PDF в программе просмотра и проверьте язык, символы, номера
пальцев и расположение элементов. Для проверки печати выберите A4, альбомную
ориентацию и масштаб 100% / фактический размер.

### Очистка вспомогательных файлов

LaTeX и `latexmk` также создают файлы `.aux`, `.log`, `.out`, `.fls` и `.fdb_latexmk`
с тем же именем задания. В `.log` записываются ошибки и предупреждения.
Вспомогательные файлы перечислены в `.gitignore` и удаляются командой очистки.
Очистка также удаляет временные файлы регистрации `lualatex<цифры>.fls`,
оставшиеся после неудачного запуска движка, только в каталогах зарегистрированных
документов. PDF и исходники TeX сохраняются.

```sh
just clean
```

В гитарной таблице используются цифры пальцев фиксированного размера 6,8 пункта
с утолщёнными штрихами для читаемости при печати. Размер и начертание шрифта
заданы в оформлении документа и не требуют параметров сборки.

### Добавление документа

Добавьте в `@documents` в [`latexmkrc`](latexmkrc) путь к исходнику TeX
относительно корня репозитория, якорь, названия закладки на английском и
русском и поддерживаемые ключи вариантов. Все зарегистрированные документы
поддерживают `language` через `\ChartLanguage` и определяют `ChartAccent`
в цветовой модели `HTML` через макрос `\ChartAccentHex` со значением
`195755` для прямой сборки. Документы с аппликатурами могут объявить
`show_finger_numbers` и использовать `\ShowFingerNumbers` (`true` или `false`).
Из реестра также формируется `@default_files` для latexmk и очистки.

## Устранение ошибок

| Признак | Действие |
| --- | --- |
| Команда `just` или `latexmk` недоступна | Установите инструмент по инструкции для своей платформы выше, откройте новую оболочку и проверьте путь к исполняемому файлу. |
| Команда `lualatex` недоступна | Откройте новую оболочку и проверьте путь к исполняемому файлу. На Windows проверьте настройку пути поиска в установщике TeX Live. На Linux используйте каталог, указанный установщиком TeX Live, если устанавливали его напрямую. |
| Отсутствует файл `.sty` или локаль Babel | Найдите файл через `kpsewhich`. Установите соответствующий пакет через TeX Live Manager / TeX Live Utility из MacTeX либо через менеджер пакетов дистрибутива Linux (`apt`, `dnf`, `emerge` или `zypper`). |
| Шрифт DejaVu Sans Condensed не найден | Проверьте оба файла `.ttf` через `kpsewhich` и установите пакет TeX Live `dejavu`. Исходник загружает эти файлы шрифтов из установки TeX. |
| Исходный файл TeX не найден | Проверьте путь в `@documents` в `latexmkrc`. Запустите `just` из корня репозитория или вложенного каталога. |
| Сборка прерывается с ошибкой LaTeX | Прочитайте первую ошибку в соответствующем файле `.log`. Проверьте `lualatex --version` и перечисленные выше пакеты. |

На macOS активные исполняемые файлы MacTeX доступны через `/Library/TeX/texbin`.
Если команда недоступна в новом окне Terminal, проверьте этот каталог и настройку
`PATH`. [Подробности установки MacTeX](https://tug.org/mactex/What_Is_Installed.pdf).

Обновления установки из дистрибутива Linux выполняются его менеджером пакетов.
Для установки TeX Live напрямую используется `tlmgr`.
[Документация TeX Live Manager в Debian](https://manpages.debian.org/unstable/texlive-base/tlmgr.1.en.html).

## Проверенное окружение

Настройки YAML, английские и русские варианты, оба сборника PDF, прямая
компиляция через LuaLaTeX, инкрементальная сборка и очистка проверены на macOS
с LuaHBTeX 1.21.0 из TeX Live 2025, `latexmk` 4.86a, `just` 1.59.0
и YAML::PP 0.43.0. Инструкции по установке в Windows и Linux сверены
с документацией поставщиков. Сборка с инструментами, установленными
непосредственно в этих системах, пока не проверена.
